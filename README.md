### 2. 🚦 [SUMO2Unity](https://github.com/SimuTraffX-Lab/SUMO2Unity) — Open-Source 3D/VR Traffic Co-Simulation Engine
[![GitHub Stars](https://img.shields.io/github/stars/SimuTraffX-Lab/SUMO2Unity?style=flat-square&logo=github&color=yellow)](https://github.com/SimuTraffX-Lab/SUMO2Unity/stargazers)
[![GitHub Forks](https://img.shields.io/github/forks/SimuTraffX-Lab/SUMO2Unity?style=flat-square&logo=github)](https://github.com/SimuTraffX-Lab/SUMO2Unity/network/members)
[![Stack](https://img.shields.io/badge/Stack-C%23%20%7C%20Unity%203D%2FVR%20%7C%20Python-blue?style=flat-square)]()
[![License](https://img.shields.io/badge/License-MIT-green?style=flat-square)](https://github.com/SimuTraffX-Lab/SUMO2Unity/blob/main/LICENSE)

> **Built for Non-Programmers:** An automated 3D/VR co-simulation platform developed at York University (SimuTraffX Lab) that empowers civil engineers, instructors, and traffic researchers to convert 2D SUMO traffic networks into interactive 3D and Virtual Reality environments **without writing code**.

- **Zero-Code 3D Road Network Generation:** Automatically parses complex 2D SUMO road geometries, intersections, buildings, and environment assets into ready-to-run 3D Unity scenes.
- **Real-Time Bi-Directional Synchronization:** Programmed the C# data exchange pipeline synchronizing 3D vehicle trajectory coordinates ($X, Y, Z$) and traffic signal timing phases every `0.02s–0.10s` for human-in-the-loop VR car, bicycle, and e-scooter simulators.
- **Peer-Reviewed Publications:**
  - 📄 *[An Open-Source Virtual Reality Traffic Co-Simulation for Enhanced Traffic Safety Assessment](https://www.mdpi.com/2076-3417/15/17/9351)* — **Applied Sciences** (2025)
  - 📄 *[SUMO2Unity: An Open-Source Traffic Co-Simulation Tool to Improve Road Safety](https://ieeexplore.ieee.org/abstract/document/10588652)* — **IEEE Intelligent Vehicles Symposium (IV)** (2024)
